# Text-feeding comparison methodology

The inherited WAV files were removed because the recording/voice provenance
and generated-media permissions were not independently established.
See [the licensing audit](../../docs/LICENSING.md).

The benchmark scripts remain available for regeneration with your own
permitted reference recording and exact transcript. Record the model revision,
voice source, permission to clone and redistribute, prompt, seed, sampling
parameters, backend, and software revision with any new published samples.

Do not infer permission to reuse an old recording from the code license.
New sample audio requires its own explicit provenance and redistribution grant.
